SHOWLINK SHORTLINK — FINAL SETUP

DATABASE
1. Run SHOWLINK_PAYMENT_LINK_CASHI_FINAL_FIXED.sql.
2. Run SHORTLINK_FINAL_COMPLETE.sql.
3. The old SHORTLINK_FINAL_COMPLETE.sql, SHORTLINK_FINAL_COMPLETE.sql,
   and SHORTLINK_FINAL_COMPLETE.sql are removed because their
   responsibilities are consolidated into SHORTLINK_FINAL_COMPLETE.sql.

FLOW
FREE: /s/{slug} -> Task1 -> Task2 -> Task3 -> FINAL -> /s/{slug}?unlocked=1
VIP: /s/{slug} -> Task1 -> Task2 -> FINAL -> /s/{slug}?unlocked=1
PREMIUM: /s/{slug} -> Task1 -> FINAL -> /s/{slug}?unlocked=1

CONTENT
Public metadata never returns content_text. Raw content is not previewed
or stored in browser storage before Final. After Final, the same /s/{slug}
layout fetches get_public_shortlink_content() and renders the multiline
content. URLs inside the content remain clickable. No .txt download.

ANALYTICS
The unlocked result records page_view once per browser session.
The Final button records original_click. Dashboard reads the
showlink_shortlink_final_dashboard view.

CPM
site_settings.shortlink_cpm controls the reference CPM. Default Rp125
is inserted only when the setting does not exist. Admin RPCs:
get_shortlink_cpm_admin() and set_shortlink_cpm_admin(p_cpm).

Dashboard aggregate data is cumulative; daily/monthly values are not
fabricated from cumulative totals.
